壹

项目概述

澜图是一个面向意大利中国留学生的学业规划 + 应试辅导服务品牌。

意大利大学实行学分制、无固定毕业年限，考试以口试为主、一年多个考期——自由度极高，也极度依赖学生的自我规划能力。大量中国留学生并非"学不会"，而是不会规划、不得方法、信息闭塞，在一次次弃考和重考中滑向延毕（fuori corso）。

澜图做两件事：先当规划师，把剩余学分拆解成一张可执行的"毕业航线图"；再当辅导员，用划重点、思维导图、真题与口试模拟，把每一科送过考线。收费与结果绑定——过科才收全款，让学生零信任成本上船。

贰

市场与痛点

市场基本盘

  • 通过马可波罗、图兰朵计划及国际生渠道，在意中国留学生长期保持在数万人规模，米兰、都灵、博洛尼亚、佛罗伦萨、罗马为主要聚集地。
  • 意大利公立大学毕业率长期偏低，按时毕业者不足半数，延毕在本地学生中尚且普遍，对语言受限的留学生更甚。
  • 现有市场上多为论文代辅、语言课程和零散私教，"规划 + 辅导 + 结果绑定"的一体化服务几乎空白。

学生的四类典型痛点

  • 不会规划：不知道先考哪科、一个考期报几门，凭感觉复习，弃考成习惯。
  • 不得方法：面对几百页意语讲义无从下手，抓不住重点，背了就忘。
  • 信息闭塞：不了解教授出题风格、历年真题、口试套路，单打独斗。
  • 缺乏督导：没有 deadline 就不学习，拖延到考前三天才翻书。

伍

服务流程

  1. 免费初谈（30 分钟）
    了解专业、剩余学分、挂科史，判断是否可接——澜图只接"愿意执行"的学生。
  2. 学业诊断 + 航线图
    拆解剩余科目，按难度与考期排布，产出专属复习日历。
  3. 签约付定 · 定金 400€
    明确科目、考期、双方义务与"包过"兑现规则，电子协议存档。
  4. 辅导执行（4–8 周）
    每周固定辅导 + 划重点讲义 + 思维导图交付，打卡督学，进度可视。
  5. 考前冲刺
    真题演练、口试全真模拟（意语问答），查漏补缺。
  6. 出分结算 · 尾款 400€
    过科收尾款并邀请学生写口碑反馈；未过则免费进入下一考期循环。
陆

获客与增长

  • 小红书内容矩阵：主账号持续输出"意大利大学生存指南"——考期规划、口试技巧、教授风格测评。干货即广告，评论区引流私域。
  • 微信私域：按城市 / 学校建群，定期免费直播"考期规划公开课"，群内转化。
  • 老带新返现：成功案例学生推荐新客，每单返 50€；延毕圈子高度重合，口碑传播极快。
  • 学长学姐分销：发展各校"课代表"，负责答疑与转介绍，按单分成，轻资产铺开城市。

差异化壁垒

对比淘宝代辅与传统留学机构，澜图的护城河是三件事的组合：结果绑定的付费模式（别人不敢承诺）、意大利本地化的科目情报库（真题、教授风格逐科沉淀，越做越厚）、规划师人设（不是卖课，而是"把你送到岸上"）。

风险与合规

风险对策
学生不执行，拖垮通过率初谈严格筛选；协议约定打卡义务；"躺平"可终止且定金不退。
通过率不及预期，尾款收不回定金 400€ 已覆盖辅导成本；讲义复用摊薄边际成本；优先接"临门一脚型"。
口碑翻车不过度承诺，宣传口径为"辅导陪跑 + 不过免费重辅"，让协议替嘴说话。
合规红线只做合法辅导：不代考、不代写、不涉任何学术不端。这既是底线，也是品牌能走长远的前提。
个人税务业务稳定后在意注册 Partita IVA（个体税号）或以国内主体收款，咨询当地会计师合规化。
